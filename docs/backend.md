# 后端：重命名、执行、写回与恢复

## 重命名与派发

- 默认每拍按序分配、提交各最多 4 条。ROB 有 16 项，PRF 有 48 项；完整 ROB tag 由 epoch 和槽位组成。组内 RAW 使用最近写者的新物理寄存器，WAW 保留按序回收链。
- ROB、RAT、PRF、保留站（RS）和 LQ/SQ 共用实际分配前缀。分配只看拍初空槽，不借用本拍派发或退休腾出的槽；新入 RS 的指令最早下一拍派发。
- 双 ALU 从旧整数 RS 选择最老就绪指令。Branch 同拍旁路可用 ALU 和 MUL/DIV 的合格写回，不直接使用 Load 写回。
- Load 与 StoreAddr 共用一个 AGU。每池可锁存一项被本拍授权写回唤醒的旧指令，后续拍从 PRF 读值再派发。锁存项保留至实际派发或冲刷；没有锁存项才选旧就绪项。

## 写回与提交

| 写回口 | 来源 |
|---|---|
| CDB0、CDB1 | 两个 ALU 各一路 |
| CDB2 | MUL 与 DIV 按 ROB 年龄共享 |
| CDB3 | Load 独占 |

写回检查完整 ROB 身份及冲刷边界。PRF 中 P0 不分配；其余寄存器的写入按写回口优先级合并，上一拍的写入记录补足同步 SRAM 读值。

提交只读取拍初的 ROB 就绪位，后续指令不能越过队首。Load 写回后仍占 LQ，直到退休；Store 退休后仍可留在 SQ，直到被缓存接收。退出 Store 会截断其后的提交。

## 执行单元

- ALU 单槽保存结果，结果被消费或取消后可同拍接收新指令。BRU 保存真实分支方向和下一 PC；JAL/JALR 的链接值与目标由 ALU 计算。
- AGU 保存地址和目标身份，下一拍交付 LQ/SQ。合格的 Load 地址可以在登记前参与缓存仲裁。
- MUL 采用 radix-4 Booth 与 CSA 三级弹性流水：部分积、压缩、最终加法。无争用时，派发后第 3 拍写回。
- DIV 采用 radix-4 SRT，商数字为 −2 到 2，递推 `W[j+1] = 4W[j] - qD`；使用 `P=4W` 域的 35/36 bit 部分余数与 9 bit QDS 估计。位宽、阈值与逐拍参考见[除法推导](_archive/20261018/docs/backend.md#44-div-实现srt-radix-4)。

## 分支恢复

广播拍读取已提交 RAT/RAS 基线。默认每个重放拍处理原 ROB 窗口的 8 个槽，最多 2 个重放拍；按冲刷前的占用数结束，而不是按保留前缀长度结束。RAT/RAS 重放至边界（含边界），PRF 按序回收年轻指令的物理寄存器。

重放期间暂停后端派发、写回和提交；缓存、AXI 及已提交 Store 继续推进。
