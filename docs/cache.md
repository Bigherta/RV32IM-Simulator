# 缓存与 AXI

## 组织

| 项目 | ICache | DCache |
|---|---|---|
| 容量与行长 | 1 KiB，64 B 行 | 8 KiB，32 B 行 |
| 组与路 | 16 组，直接映射 | 128 组、2 路，PLRU 替换 |
| 请求 | 2 个取指包槽 | 8 个请求槽、4 个 MSHR |
| 写策略 | 无 CPU 写口 | 写回、写分配 |

## 查询与回填

- I$ 按同步读时序返回命中包，缺失由 AXIFetch 取回整行。冲刷可取消取指请求的逻辑结果，但已接受的 AXI 返回仍须排空。
- D$ 的同一端口冲突按回填、Store、查询的顺序处理。无旧 Store 同行或 MMIO 冲突、目标组未锁定且读口可用时，新 Load 可在接受沿启动同步读，最早下一拍返回。
- D$ 支持同行 Load 合并。AXIData 从所需字开始轮转读，并在 R 握手后寄存字响应；身份与字节范围合法且无 Store 冲突时，不必等整行回填即可返回 Load。完整回填仍按整行安装。
- 4 项命中位置表由 Load 命中训练，可供合格队首 Store 直接写入。普通 RAM Load 可触发下一行预取；需求优先，预取共享请求与 MSHR 信用，不产生 CPU 返回。

## AXI

`AXIFetch` 和 `AXIData` 经 `AXIBus` 共享外部 AXI4-Lite。AXIFetch 有 4 条行信用；AXIData 读写共享 8 项行请求与载荷信用，AW 和 W 独立握手。外部 Slave 的每通道 16 项队列与主机信用分开计数。
