# 前端：取指、译码与预测

## 取指与译码

`FetchUnit → ICache → FQ → Decoder/IQ`。默认每拍最多取指 2 条、译码 4 条，FQ / IQ 分别为 8 / 8 项。

I$ 命中可组成最多 2 条的取指包，不跨缓存行；遇到首条控制流指令时截断。

IQ 为空时，FQ 队首的整组指令可直接参与分配；只有整组可分配才跳过 IQ。

## 分支预测

方向使用 Tournament；目标侧有 32 项 BTB 和 8 项 RAS，预测检查点有 64 项。恢复时从已提交栈重放存活的 ROB 指令。
