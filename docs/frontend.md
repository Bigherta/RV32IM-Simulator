# 前端：取指、译码与预测

## 取指与译码

数据流为 `FetchUnit → ICache → FQ → Decoder/IQ → 后端`。默认每拍最多取指、译码各 4 条，FQ 和 IQ 各 8 项，I$ 有 2 个取指包槽。

- I$ 命中时从当前 PC 连取最多 4 条，可跨 16 B 边界但不跨 64 B 缓存行；遇到第一条控制流指令就截断，并只预测该指令。冷缺失按单条取指。
- 取指包按实际条数占用信用，每条指令有独立 PC 和预测检查点 ID。队列可使用本拍实际出队释放的空间。
- IQ 为空时，FQ 队首可整组直达分配；FQ 与 IQ 都为空时，I$ 返回包还可直接译码。只有整组都能分配才跳过 IQ，否则整组进入 IQ，不重复消费。

## 分支预测

| 资源 | 默认配置 |
|---|---|
| 方向预测 | Tournament：局部表 256×3 bit、全局表和选择表各 256×2 bit |
| 历史与检查点 | 256 项 1 bit 局部历史、8 bit GHR、64 个检查点 |
| 目标与返回 | 32 项 BTB，投机 RAS 和已提交 RAS 各 8 项 |

检查点保存预测时的历史和分量预测；条件分支用执行得到的实际方向训练。预译码识别 JAL/JALR 的 x1、x5 链接寄存器提示：JAL 按 `rd` 入栈；JALR 在 `rs1` 为链接寄存器且 `rd != rs1` 时出栈，在 `rd` 为链接寄存器时入栈。两个动作同时发生时先出后入；同一链接寄存器只入栈。

## 恢复

错误预测时清除错路取指并回卷预测上下文。RAS 从已提交栈重放存活 ROB 指令；默认四取指档在重放期间暂停新取指和取指包交付，在途 I$/AXI 事务仍可排空。
